# Codegen Playwright Project

This project is a Node.js setup for end-to-end testing using Playwright, ready for cloud deployment.

## Features
- Playwright for E2E browser testing
- Example test in `tests/example.spec.js`
- Dockerfile for cloud CI/CD

## Usage

### Local Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Install Playwright browsers:
   ```bash
   npx playwright install --with-deps
   ```
3. Run tests:
   ```bash
   npm test
   ```

4. Launch Playwright codegen (with spinner/loader for headless environments):
   ```bash
   npm run codegen:spinner -- https://demos.reytheme.com/san-francisco/
   ```

### Docker
Build and run tests in Docker:
```bash
docker build -t codegen-playwright .
docker run --rm codegen-playwright
```

## Project Structure
- `package.json` — Node.js project config
- `Dockerfile` — for cloud deployment
- `tests/` — Playwright test specs
